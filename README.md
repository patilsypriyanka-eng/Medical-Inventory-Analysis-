# Medical Inventory Analysis 💊

## About the Project

In this project, I explored medical inventory data to understand how products are selling and how inventory is performing. The main goal was to identify useful patterns in sales, product movement, and returns.

## Tools Used

- Python
- Pandas
- Power BI
- Microsoft Excel

## What I Worked On

- Cleaned and prepared the data for analysis using Python.
- Explored sales and product information to understand business trends.
- Analyzed product returns to identify possible areas for improvement.
- Created visualizations to make the data easier to understand.
- Built a Power BI dashboard to present key findings.

## Key Learnings

Working on this project helped me improve my data cleaning, analysis, and visualization skills. I also learned how to use Python and Power BI together to turn raw data into meaningful insights.

## Dashboard

I used Power BI to present important sales and inventory metrics in a clear and interactive format.

## Skills Used

Python | Pandas | Power BI | Excel | Data Cleaning | Exploratory Data Analysis | Data Visualization

## Conclusion

This project gave me practical experience in analyzing medical inventory data and understanding product sales and returns. It also helped me build confidence in working with data and presenting insights through dashboards.
